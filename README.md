## 💳 TrustLens

### Trust Scoring for the Credit-Invisible

TrustLens is an AI-powered alternative trust-scoring system designed for people with limited traditional credit history.

The system combines behavioural signals, alternative data, and anti-gaming mechanisms to create a more reliable trust profile.

### Key Features

- Alternative Trust Scoring
- Behavioural Analysis
- Anti-Gaming Layer
- Risk Detection
- Alternative Data Signals
- FastAPI Backend

### Technology

`Python` `AI` `FastAPI` `Behavioural Analysis` `FinTech`
